# PineappleCAS 汉化版：根式化简（实验功能）

本分支在中文「化简」菜单增加 **根式化简** 复选框（默认开启），并移除单独的「转根式」菜单。它同时保留此前的中文 UI、输入输出示例、负分数指数转换，以及普通化简/求值/展开/求导功能。

## 使用方法

1. 在 TI-84 Plus CE 的 MODE 中选择 MathPrint。
2. 在 Y= 的 Y1 写入一个完整表达式（包含两个根号时，两个根号同样放在 Y1 中），例如 `sqrt(8)+sqrt(2)`。
3. 运行 `prgmPCAS`。程序上方选择输入 Y1、输出 Y2。
4. 左侧进入 **化简**，右侧保持「根式化简」已勾选，移动至底部「化简」并按 ENTER。若不希望进行根式转换，可取消勾选以沿用原逻辑。
5. 等待「成功」，按 ENTER 关闭结果弹窗，然后 CLEAR 退出；在 Y= 的 Y2 查看 MathPrint 原生根式表达式。
6. 「示例」按钮仍存在，在「化简」中预览 `sqrt(8)+sqrt(2) -> 3sqrt(2)`。

**TI 键盘注意：** 减法使用普通 `-` 运算键，负指数使用 `(-)` 负号键。这两种符号在计算器内不是同一个 token。

## 受支持的例子

- 同类根式相加：`sqrt(8)+sqrt(2)` → `3sqrt(2)`，`sqrt(18)+sqrt(8)` → `5sqrt(2)`。
- 同类根式相减：`sqrt(8)-sqrt(2)` → `sqrt(2)`。
- 正整数平方根相乘：`sqrt(2)*sqrt(3)` → `sqrt(6)`，`sqrt(2)*sqrt(8)` → `4`。
- 三次根式：`3root(2)*3root(4)` → `2`。
- 不可合并：`sqrt(2)+sqrt(3)` 保持两个根式，不错误地变成 `sqrt(5)`。
- 分数指数转根式：`X^(5/3)` → `(3rootX)^5`；`X^(-5/3)` → `1/(3rootX)^5`。

## 数学条件和限制

- **相加**：必须是提取完全幂因子之后根指数和被开方数完全一致的同类根式。
- **相乘**：只自动合并相同根指数、根号下已知为正整数的根式。
- **负数开偶次根**：不会套用实数根式合并公式；本版本不实现复数主值分支运算。
- 目前数字根式的提取/乘法处理限于不超过 100000 的正整数被开方数，根指数限 2–6；较复杂表达式暂时保留未合并形式。
- 普通符号表达式的化简功能仍在；带有根式的表达式会使用较保守的代数步骤，避免旧版通用规则对根式操作产生不正确变化。
- 原生 MathPrint 的最终显示排版仍需 TI-84 Plus CE 真机验证；桌面端自动化测试不能替代硬件验证。

## 开发与验证

本分支增加 `src/cas/radicals.c`，复用原有 AST 和根号导出器，避免先输出根号再调用 normalize 又变回幂的循环。根式计算先保留代数意义，再进入专用根式提取与合并阶段，最后输出 TI 原生 MathPrint 根号 token。

测试：`make -f pc.makefile && ./bin/pineapple test tests-radicals.txt && ./bin/pineapple test tests-radical-combine.txt`。CI 使用 CEdev v15.0 编译 `PCAS.8xp`，需要真机确认实际输入、界面布局、计算输出。

源码采用独立分支，默认主分支 master 未修改。

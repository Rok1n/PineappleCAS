# PineappleCAS 汉化版：分数指数转根式（测试功能）

## 功能说明

新增左侧第五个菜单 **转根式**。输入 `X^(5/3)`，选择此模式，输出 `(³√X)^5` 对应的 **TI-84 Plus CE 原生根号 token**（不是中文字体绘图生成的根号）。

内部 AST 转换规则是：

```
POW(X, DIV(5, 3)) -> POW(ROOT(3, X), 5)
POW(X, DIV(1, 3)) -> ROOT(3, X)
```

原来的“化简 / 求值 / 展开 / 求导”逻辑保持不变，新的重写仅在“转根式”模式执行。为避免将根式再次转换回指数，此操作完成后直接导出，不继续执行通用化简。

## 使用方法

1. 在计算器的 `MODE` 中选择 `MathPrint`（而不是 `Classic`），确认数学符号以模板显示。
2. 打开 `Y=`，在 `Y1` 输入 `X^(5/3)`，其中分数要带括号。
3. 运行 `prgmPCAS`；顶部输入选择 `Y1`，输出选择 `Y2`（不要选择覆盖自己要保留的变量）。
4. 使用方向键在左侧选择 **转根式**，按右键或 ENTER 进入右侧，选中 **转根式** 按 ENTER。
5. 等待“成功”；选择“关闭”，按 `CLEAR` 退出。
6. 回到 `Y=`，切换到 `Y2` 查看生成的根式。在 MathPrint 模式下，应以数学公式布局显示。

## 支持范围

- 正负整数分子 `m` 与非零整数分母 `n`，如 `X^(5/3)`、`X^(-5/3)`、`X^(-1/2)`；负分数指数输出倒数。
- 负整数指数如 `X^(-2)` 输出 `1/X^2`，`X^(-1)` 输出 `1/X`。
- `X^(1/n)` 输出 n 次根号，不额外显示一次幂。
- 也识别存为单个分数值的指数，如 `X^0.5`。
- 支持表达式嵌套和多个分数指数，未匹配的部分保持不变。
- 符号指数、无法识别的指数表达式暂时保留原式；底数为字面值 0 且指数为负时也保留原式（数学上无定义）。
- 偶数次根号在实数范围内要求底数非负；本程序不会自动判定表达式定义域。

## 测试与已知限制

已通过宿主机 CAS 测试 12/12，并使用 CEdev v15.0 生成 `PCAS.8xp`。CI 测试验证表达式运算树结构和编译成功，**没有真实 TI‑84 Plus CE 的 MathPrint 屏幕截图验证**。仍需真机确认 Y2 内根号的排版。
